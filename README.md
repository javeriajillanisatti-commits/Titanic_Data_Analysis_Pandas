# Titanic Data Analysis Using Pandas

## Introduction

This project focuses on analyzing the Titanic dataset using Python and the Pandas library. The purpose of this project is to understand the dataset, handle missing values, generate summary statistics, and perform basic exploratory data analysis (EDA) to find useful information from the data.

## Dataset Description

The dataset used in this project is the Titanic passenger dataset. It contains information about passengers who traveled on the Titanic ship. The dataset includes different features such as passenger ID, name, age, gender, passenger class, fare, and survival status.

This dataset is useful for data analysis because it contains both numerical and categorical data along with some missing values that require cleaning before analysis.

## Tools and Technologies Used

- Python
- Pandas Library
- CSV Dataset
- Visual Studio Code

## Data Cleaning Process

Before performing analysis, the dataset was cleaned using Pandas. The following steps were performed:

- Checked the dataset for missing values.
- Filled missing Age values using the average age of passengers.
- Filled missing Embarked values using the most common value.
- Removed the Cabin column because it contained a large number of missing values.
- Verified the dataset after cleaning to ensure better data quality.

## Exploratory Data Analysis (EDA)

Basic exploratory data analysis was performed to understand the dataset. The following tasks were completed:

- Displayed the first few records of the dataset.
- Checked dataset information and data types.
- Generated summary statistics to understand numerical features.
- Counted the number of survived and non-survived passengers.
- Analyzed passenger gender distribution.
- Checked passenger class distribution.
- Calculated the average passenger age.

## Key Findings

After analyzing the dataset, the following observations were found:

- Missing values were successfully handled during the cleaning process.
- The dataset provides useful information about passenger survival.
- Passenger class and gender are important factors when analyzing survival patterns.
- Pandas provides simple and efficient methods for cleaning and analyzing datasets.

## Conclusion

This project helped in understanding the basic process of data analysis using Pandas. By cleaning the dataset and performing exploratory analysis, useful patterns and information were extracted from the Titanic dataset.

The project demonstrates how Python and Pandas can be used to work with real-world datasets.
